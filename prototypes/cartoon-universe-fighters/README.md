# Cartoon Universe Fighters — isolated prototype

Open `index.html` locally in a browser. This is an original, dependency-free canvas fighting-game foundation. No production navigation or backend changes are included.

Controls: A/D move, W jump, J punch, K kick, L block, R restart. Mobile: on-screen controls.

The CPU opponent is playable. Online multiplayer is **not implemented** in this prototype; it requires authenticated, server-authoritative rooms, input validation, rate limits and reconciliation before launch.
